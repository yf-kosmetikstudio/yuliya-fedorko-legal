## About the project

This repository contains the static website for **Yuliya Fedorko**.  
The site is prepared for public publishing via **GitHub Pages** and includes the main legal and service-related pages required for a professional online presence.

### Main pages
- Home
- Impressum
- Datenschutz
- 404 page

### Features
- Static and lightweight structure
- Responsive layout
- SEO-oriented markup
- Sitemap and robots.txt
- Custom domain support via `CNAME`
- Ready for GitHub Pages deployment
